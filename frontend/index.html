关于本项目

这是一个前后端分离的多步骤任务规划 Agent：后端 Flask 提供 REST 接口，前端为独立静态站点，通过 CORS 跨域调用。

  • 后端：规划模块 → 执行器 → 上下文 → 汇总，全流程可测
  • 工具：计算器、时间查询、本地模拟检索、备忘读写
  • 测试：pytest 全离线运行，不产生真实模型请求

启动：cd backend && flask --app app run --port 8000，浏览器打开 http://127.0.0.1:8000。
